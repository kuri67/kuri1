# 未完成的世界 · 绘桥之章

使用 Vite、TypeScript、Three.js 与 Rapier 构建的四关卡可玩原型。

## 运行

需要 Node.js 22.12+（已验证 Node 24）。

```sh
npm ci
npm run dev -- --port 5173
```

构建：`npm run build`。生产预览：`npm run preview`。

## Windows 本地运行（PowerShell / Windows Terminal）

1. 从 https://nodejs.org/ 安装 **Node.js 24 LTS**（包含 npm）。安装后重新打开终端。
2. 将 ZIP **完整解压**到本地目录，例如 `C:\Games\unfinished-world`。不要在压缩包内直接运行文件。
3. 打开 PowerShell，进入包含 `package.json` 的项目文件夹：

   ```powershell
   cd "C:\Games\unfinished-world"
   node --version
   npm.cmd --version
   npm.cmd ci
   npm.cmd run dev -- --port 5173
   ```

   如果解压后多了一层 `unfinished-world` 文件夹，先进入该层再执行命令。
4. 保持终端运行，用 Chrome 或 Edge 打开 **http://localhost:5173/**。如果端口被占用，Vite 会打印实际使用的地址，请以终端为准。
5. 停止服务器：在终端按 `Ctrl+C`。下次运行只需进入项目目录，再执行 `npm.cmd run dev -- --port 5173`，不必重复安装依赖。

这里使用 `npm.cmd`，避免 PowerShell 的脚本执行策略阻止 `npm.ps1`，不需要降低系统执行策略。安装依赖需要联网访问 npm；运行无需 API 密钥、数据库或额外美术文件。请勿双击 `index.html` 直接启动，游戏需要 Vite 提供模块和 WebAssembly 加载服务。

### Windows 构建与生产预览

```powershell
npm.cmd run build
npm.cmd run preview -- --port 4173
```

然后打开终端打印的地址（通常为 http://localhost:4173/）。构建结果位于 `dist`。

### 常见问题

- 找不到 `node` 或 `npm.cmd`：重新安装 Node.js，确保添加到 PATH，关闭并重新打开终端。
- `npm ci` 失败：先检查网络及 Node 版本；保留 `package-lock.json`，不要为绕过安装错误关闭 TLS 验证。
- 画面空白或提示 WebGL 不可用：使用最新版 Chrome/Edge，启用浏览器图形加速并更新显卡驱动。
- 角色不动：先点击游戏场景让网页获得焦点，再使用 WASD；桥板高出地面，需要按空格跳上去。

Windows 步骤为本地操作说明；当前构建和浏览器测试在 Linux 云环境中执行，未在 Windows 实机验证。仅运行游戏不需要配置测试浏览器；在 Windows 跑自动化测试时，先执行 `npx.cmd playwright install chromium`，然后执行 `npm.cmd test`。配置会自动选择 Playwright 的浏览器。

## ZIP 包内容

包含 `package.json`、`package-lock.json`、`index.html`、TypeScript 配置、`src/` 全部源码、Playwright 配置与 `tests/`。角色、场景、材质均由源码程序化生成；Rapier 的 WASM 随 npm 依赖安装，不存在遗漏的外部贴图、模型或音频资源。

不包含 `.git`、`node_modules`、`dist`、测试截图和临时输出。依赖通过 `npm ci` 按锁文件恢复。

## 操作与通关

- WASD / 方向键移动（沿场景世界轴），空格跳跃，E 进入绘画。
- 绘画时物理暂停，主画布旁保留缩小的场景。按住鼠标画一个不自交的封闭轮廓；末点需接近起点。
- 支持撤销当前轮廓、清空重画，或收回最近一件已生成作品修改。可创建多件作品，无墨水和件数限制。
- 点击完成后，拖动场景中的半透明作品，或用滑块/滚轮缩放。金色边框限定放置区域，越界作品显示红色并禁止确认。
- 确认后恢复物理。轮廓为物体正面截面，沿纵深挤出固定深度；轮廓的粗细决定实体厚薄。碰撞体由轮廓三角剖分后的凸棱柱组合构成，不使用包围盒替代轮廓。
- 建议先试示例桥板，将其放在深沟中央。两端需充分搭岸。桥板高出地面，需要空格跳上桥；向右侧青色门廊前进即可通关。
- 掉落后自动回到左岸，作品保留；右上角重新开始清除作品并复位。

## 四章流程与解法

使用页眉的关卡菜单可直接体验任意章节；通关后点击“进入下一章”连续游玩。重新开始只重置当前章。进入新章会清理作品、机关状态和旧关卡碰撞体。

绘画台新增“部件用途”，选用途后自由画封闭轮廓，或使用示例。放置阶段可调整 X/Y/Z、缩放和角度，也可以拖动和滚轮操作。用途定义材料与连接方式，轮廓决定部件形状；重物更重，浮筒更轻。坐标输入方便精确组合，关卡提示与金色标记指明连接位置。

### 第一章：绘桥之章

保留原来的跨沟玩法。示例木板居中放置，两端搭岸，再跳上桥走向出口。

### 第二章：树根之森

巨石不能靠角色推动，须通过装置抬升后走过通道。

- 杠杆路线：支撑块放金色支点 X=-2，长木板居中搭在支点上，再将重物放 X=-4.5、底部 Y=3.3。示例默认坐标可直接形成组合。装置将重物力矩传给古老的棘轮举石机。走侧边 Z≈1.4 可绕过木板，通过巨石下方。
- 滚轮路线：选择“支撑块”用途画长条，作为固定斜坡放 X≈-5、角度 -20°；圆形滚轮从斜坡左上方落下，向右滚动撞击举石机。尺寸、质量、速度影响传递的冲量，不够时可以增加滚轮或调整斜坡。
- 牵引路线：在 X=-5 树根连接点放牵引绳，再放重物，重物下降产生牵引。

### 第三章：无声钟城

- 齿轮路线：选择齿轮，画圆或用示例，直径约 2，放在金色空环 X=-2、Y=2.7、Z=-2.3。尺寸过小或位置不对不会接通。
- 滑轮路线：在左侧 X=-6、Y=4 安装滑轮，放配重从其下方下降，为装置蓄能。
- 杠杆路线：X=-3 安装支撑块和长木板，在左端 X=-6 放重物，棘轮机构分段蓄能。
- 动力就绪后，走到中央平台，空格跳上去，按 F 或点击“启动升降台”。乘台上升至 Y=6，再走向右侧出口。未接通动力、未站上平台时不能启动。

### 第四章：无名之海

- 示例船体放在 X=-7，跳上船后开始航行；登船前自动系泊。海面单件横向跨度最多 8，无法用一根超长桥板直接连接相距 18 的两岸。
- 风帆路线：在船体附近画船帆，确认后自动与附近船体固定连接，利用持续的向右风力推进。
- 木筏路线：组合浮筒与木板，相距小于 4 单位的相邻部件自动连接，借海流航行。
- 牵引路线：左岸 X≈-7 放牵引绳或滑轮，浮台通过对岸预设锚点向右牵引。
- 浮力根据浸没比例和绘制体积计算，重物可能压沉船体；A/D、W/S 在船上移动并小幅调整航向。避开偏离中央航线的礁石，到右岸跳下船，走向母亲留下的画。

## 原型边界

角色、森林、钟城、海面和画作均为程序化简化造型；没有最终角色资产、复杂剧情和音效。支持四章独立选择与连续通关。

Rapier 负责自由部件碰撞、重力、滚动、落水及船体连接。机关使用明确的**简化机械模型**：杠杆按部件位置和质量计算力矩，棘轮举石机抬石；齿轮按直径与轴位判断是否接通理想恒速动力源；配重、滑轮用于蓄能，载人平台为运动学刚体。牵引绳是理想传力连接件，不模拟软绳弯曲。浮力在船体四角按截面尺寸和浸没比例分布计算，不是流体模拟；风力施加于船体，非气动模型。部件依然需要正确组合，单纯创建任意物体不会自动解锁关卡。

绘画为单笔、不自交的封闭轮廓，修改按创建顺序收回。轮廓挤出固定纵深（浮筒深度为 3，其余为 1.5，均受整体缩放影响）。部件用途由玩家选择，系统不做语义图像识别。原型支持鼠标/触屏绘画和放置，角色操作需要键盘。复杂或极细轮廓仍可能不适合物理结构。
